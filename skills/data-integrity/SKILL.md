# 데이터 정확성 점검

## 사용할 때
CSV·JSON·XLSX 자료를 요약·결합·계산하거나 표를 작성할 때. 데이터가 없는 작업에서는 사용하지 않습니다.

## 절차
1. 한 행의 의미·식별키·중복 의미·측정 단위·기간을 확인합니다.
2. 열 이름·결측 후보·형식을 조사하되, 원본의 값을 자동 삭제하거나 0으로 대체하지 않습니다.
3. 조인이 필요하면 관계 유형, 좌우 키 중복, 미매칭, 예상 출력 행 수를 먼저 계산합니다.
4. 비율은 분자·분모와 모집단을 명시합니다. 서로 다른 분모의 행별 비율을 함부로 평균하지 않습니다.
5. 명시된 규칙만 판정하고 경계값 포함 여부·근거 출처를 기록합니다.
6. 독립적으로 확인 가능한 작은 표본을 손으로 계산해 결과와 대조합니다.
7. 부분 처리와 전체 검증, 정상 결과와 미확인 조건을 구분합니다.

## 결과
- 선택한 파일·열·키·단위
- 실제 계산식과 확인한 근거
- 중복·미매칭·분모 0 등 위험
- 실행한 검증과 남은 불확실성

## 금지
규격·수율 기준·결측 처리 정책을 추측해 넣거나 사용자 데이터를 외부 서비스로 전송하는 행위.
