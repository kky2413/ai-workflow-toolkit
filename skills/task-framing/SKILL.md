# 문제를 정확히 정의하기

## 사용할 때
낯선 요청을 받았거나 결과물·완료 기준이 불명확할 때. 요구가 명확하면 단계를 간소화합니다.

## 수행 방법
1. **실제 프로젝트의 README**와 기존 작업물을 확인합니다. 참고 도구의 README와 혼동하지 않습니다.
2. 요구를 확정 사실, 임시 가정, 확인해야 할 질문, 명시적 제외 범위로 구분합니다.
3. 파일명·결과 형식·성공 조건이 제공된 경우 원문과 일치하게 유지합니다.
4. 질문은 답을 모르면 작업 결과가 달라지는 핵심 질문부터 우선합니다. 무관한 질문을 반복하지 않습니다.
5. 작은 입력으로 실제 출력 하나를 만드는 첫 단계와 그 검증 명령을 제안합니다.
6. 해결되지 않은 가정을 임의로 사실로 확정하지 않습니다.

## 결과
- 확인한 필수조건과 출처
- 미해결 질문
- 우선 구현 기능
- 성공을 확인할 실제 실행 방법

## 금지
외부 업로드·개인 토큰 설치·설정 우회·실제 프로젝트를 참고 키트로 덮어쓰기.
