# 짧고 정확한 작업 인계

## 사용할 때
대화 맥락이 길거나 작업자를 바꾸거나, 중단 뒤 같은 프로젝트를 이어가야 할 때.

## 절차
1. 현재 실제 폴더, 수정된 파일, 실행 가능한 진입 명령을 확인합니다.
2. 완료 항목은 실제 파일과 테스트 근거가 있는 것만 기록합니다.
3. 중요한 의사결정·그 근거·포기한 대안·남은 위험을 1회만 정리합니다.
4. 바로 다음에 할 작업 1~3개와 확인해야 할 경로를 적습니다.
5. 기존 인계 문서가 있으면 비교하고 필요한 부분만 갱신합니다. 근거 없이 예전 기록을 초기화하지 않습니다.
6. 새 세션에서 먼저 실제 파일 상태를 다시 확인한 후 이어 갑니다.

## 결과
- 현재 프로젝트 위치와 실행법
- 이미 구현·검증한 것과 근거
- 보류·실패 항목과 다음 행동
- 확정되지 않은 업무 질문

## 금지
미실행 테스트를 완료라고 기록하거나, 새 대화에서 모든 설정·설치를 불필요하게 반복하는 행위.
