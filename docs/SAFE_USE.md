# 안전 사용 원칙

## 현재 환경의 규칙이 우선합니다
공개된 코드라고 모든 환경에서 Clone·실행할 수 있는 것은 아닙니다. 프로젝트 README, 작업 공간 권한, 네트워크·데이터 처리·실행 승인 정책을 먼저 확인합니다.

## 포함하지 않는 기능
- 개인 계정·외부 AI·API 키 자동 연결
- 외부 서버로 입력·보고서·대화 기록 업로드
- Git Push, 원격 배포, 감시·백그라운드 작업, 자동 업데이트
- 샌드박스 우회, 승인 무력화, 감독 설정 변경
- 전역 Codex 설정 편집, Hook 자동 실행, MCP 자동 설치
- 외부 웹 주소 조회. 단, http_smoke.py의 사용자가 명시한 localhost GET 확인은 예외입니다.

## 원본 보호
원본 데이터는 읽기 대상으로 유지합니다. 결과를 별도 경로에 쓰고 출력 파일이 이미 있으면 덮어쓰지 않는 도구가 많습니다. .gitignore만으로 추적 중인 비밀 파일을 보호할 수 없으므로 공유 전 내용을 직접 검토하세요.

## 검증의 의미
- 도구 실행 성공은 **프로그램이 오류 없이 끝남**을 의미할 뿐입니다.
- 테스트 통과는 **실행한 테스트 범위에서** 기대와 일치한 것입니다.
- 업무적으로 정확하다는 주장은 집계 기준과 원본 데이터 검증이 추가로 필요합니다.
- 검증하지 못한 부분은 미검증이라고 남겨야 합니다.

## 다른 공개 자료의 활용
설계 원칙을 참고하되 다른 저장소의 코드를 그대로 수집하거나 동일한 파일 구조를 복제하지 않습니다. 제3자 코드를 실제로 복사·배포할 경우에는 원본 라이선스와 고지 의무를 따로 확인하세요. 이 저장소에는 제3자 도구 자동 다운로드 기능이 없습니다.
